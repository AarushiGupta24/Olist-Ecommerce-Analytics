# Olist E-Commerce Analytics

## Project Overview
Analyzed 99K+ e-commerce orders using MySQL and Power BI to identify sales trends, customer patterns, product performance, and payment insights.

## Tools Used
- MySQL
- SQL
- Power BI
- DAX

## Key Analysis
- Monthly revenue trends
- Top-performing product categories
- Order status distribution
- Payment method analysis
- Revenue by customer state

## Project Files
- `Olist_Analysis.sql` – SQL queries used for analysis.
- `Olist_Dashboard.png` – Power BI dashboard preview.
